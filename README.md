# 🎁 Segunda sorpresa

Página web interactiva en un solo archivo (`index.html`). No necesita instalar nada.

## Publicarla en GitHub Pages (gratis)

1. Entra en https://github.com con tu cuenta.
2. Pulsa **+ → New repository**. Ponle un nombre distinto al del primer regalo y difícil de adivinar, por ejemplo `sorpresa2-m4p9z`. Márcalo **Public** y pulsa **Create repository**.
3. Pulsa **uploading an existing file**, arrastra `index.html` (y `.nojekyll` si quieres) y pulsa **Commit changes**.
4. Ve a **Settings → Pages**. En **Source** elige **Deploy from a branch**, en **Branch** elige `main` y `/ (root)`, y pulsa **Save**.
5. Espera 1–2 minutos y tu enlace será `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.
